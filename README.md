# Collectto

Rede social mobile para colecionadores — organize suas coleções, catalogue itens e conecte-se com outros colecionadores.

## 📋 Visão Geral

O Collectto é um aplicativo mobile em React Native que une **gestão pessoal de coleções** e **interação social** em uma experiência simples e visual. Usuários podem criar coleções, catalogar itens com fotos e acompanhar publicações de outros colecionadores.

## 🚀 Quick Start

### Pré-requisitos

- Node.js 20+
- npm 10+
- Expo Go (para testes rápidos) ou Android Studio / Xcode (para emuladores)

### Execução Local

```bash
# Instale as dependências
npm install

# Inicie o bundler Expo
npm run start
```

Para limpar cache em caso de comportamento estranho:

```bash
npm run cache:clear
```

### Validação antes de PR

```bash
npm run validate
```
